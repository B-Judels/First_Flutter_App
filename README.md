# First_Flutter_App
## About Repo:

This is a simple monthly expense tracking app, but the whole point is to learn flutter practically and to get started with mobile app development and publishing on Play Store for other future projects.

## Getting Started:

If you also want to build apps using Flutter, these are some recourses that I found useful:

- For a quick feel of Dart and Flutter to get started without installation: <br>
[Intro to Flutter 1h course on Codecademy](https://www.codecademy.com/enrolled/courses/intro-to-flutter)

- From installing Flutter to building your first app: <br>
[10 Video YouTube guide by: @John Elder](https://youtu.be/VFDbZk2xhO4?si=i9Xq-mTfYxlPe_QZ)

- Adding a Sqflite database to your app for local storage: <br>
[Sqflite tutorial on YouTube by: @Learn Flutter with Me](https://youtu.be/noi6aYsP7Go?si=uodZtj8fgbvaxSRO)

- Adding a Pie Chart with section data to your app: <br>
[FL Chart Flutter Guide on YouTube by: @Hussain Mustafa](https://youtu.be/6gZ92SuzJ98?si=g4YNY1YE_JYJTtIG)

For more help getting started with Flutter, view the
[official online documentation](https://docs.flutter.dev/), which offers tutorials,
samples, guidance on mobile development, and a full API reference.
